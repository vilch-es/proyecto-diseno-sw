# Proyecto Análisis y diseño de Software
> Proyecto propuesto por el profesor Edgardo Ortiz, en el Semestre 1 del año '26 con el objetivo de dividir el negocio de YouTube en 6 bounded contexts (desde Domain-Driven Design).

#### Integrantes
- Valentín Campos
- Agustín Vilches
- Josefa Zúñiga

> [!NOTE]
> **Notas de interés**  
> Para efectos de los commit messages, BC hace referencia a bounded context 🤓
> 
> **Distribución de Bounded Contexts:**
> - Valentín: Catálogo y Audiencia.
> - Agustín: Publicación y Descubrimiento.
> - Josefa: Monetización y Publicidad.
